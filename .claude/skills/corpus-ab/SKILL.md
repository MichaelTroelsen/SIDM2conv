# Corpus A/B, with a restore you can prove

The shape is always the same, and the two steps people skip are the **restore**
and the **proof that the restore worked**.

## Procedure

**1. Snapshot before you touch anything.**

```bash
py -3 .claude/skills/corpus-ab/corpus_hash.py --save <scratch>/before.json
```

**2. Scope it to a named subset.** A corpus-wide A/B is two full sweeps; a
bounded one answers the same question in minutes. Pick the songs deliberately
and **say which** in the result — the sample is part of the number.

> Choose for the DEFECT, not for speed. Three cycles of longest-first sampling
> found zero base-window firings across 251 windows; switching to *short* songs
> found one in ten files, because the failing window was a 40-frame tail.

**3. Run arm A, measure, run arm B, measure.** Both arms at the **same** `-j`
and through the **same** builder — a difference in either is a confound, not a
result.

**4. Restore.** Re-run the default arm over the same subset.

**5. Prove it came back.**

```bash
py -3 .claude/skills/corpus-ab/corpus_hash.py --check <scratch>/before.json
```

## What restore means, exactly

**Restore the FIXED file, not the pre-task backup.** Recorded: after two mutation
checks I copied back the pre-patch snapshot and silently reverted my own change.
Snapshot the *patched* file for mutation work; the pre-task copy is for reverting
a change you have decided to abandon.

**Check provenance, not just bytes.** Artifacts carry a `.prov` sidecar. After
restoring, no artifact should still carry the experiment's flags:

```bash
grep -l "FILT_LEAD=4" out/sdi/*.prov      # expect no matches
```

The stamp reads the **environment**, so a default build that really runs at
`FILT_LEAD=64` stamps the same empty `flags` as a build with no flags at all.
Two artifacts with different effective flags can be indistinguishable by
provenance — set the control arm through env vars so it *is* distinguishable.

## What a build writes beyond its own output directory

Any `bin/build_*_native_song.py` also rewrites four shared files, because the
include generation and assembly happen **before** emission:

    drivers_src/mon/layout.inc      drivers_src/romuzak/layout.inc
    drivers_src/mon/freqtable.inc   out/romuzak_driver.prg

Measured with `emit_one` stubbed: the six artifact directories hashed identically
before and after, and all four of those changed anyway. They are gitignored build
products regenerated by any later build — but "the probe emits nothing" is false
about them, and a task must declare them.

## Reporting

State the sample size and how it was chosen. State what did **not** move as well
as what did. If both arms are identical, say so plainly — a zero delta is a
result, and `fidelity_common.exercised()` exists because a zero delta between two
things that could not have differed is not.
