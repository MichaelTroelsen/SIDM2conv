The out-of-range arp read is **FIXED** (v3.25.0): an arpeggio offset can push the note index past the 96-entry frequency table into the player's own per-voice variables, where the real player reads **live RAM** and an image-based model reads the frozen bytes. This was first recorded as needing "a real memory array" — an over-estimate; the model only needs the addresses it can already NAME, so `_var_addr_map` inverts the seed sources into `{address: (attribute, voice)}` and the table read consults it **only past the table**. **Layout-seeded population 99.98% → exactly 100.00% (0 misses of 53,569)**; second build 99.81% → 99.89% (84 → 47). The split IS the evidence: the fully-mapped population goes to exactly 100 while the partially-mapped one keeps a proportional remainder, which is what the mechanism predicts and coincidence does not. The seeding matters because the player's per-voice variables live INSIDE the loaded module image: their power-on values are the bytes the editor saved, not zero, and assuming zero costs the first note of every voice one vibrato tick of phase. Alignment was **measured, not fitted** — offset 0 is a sharp peak (100.0% vs 50.1%/51.7% at ∓1), pinned by a test. ## Understanding the metrics

- **Frame accuracy** (wired pipeline): % of frames whose SID register writes match the original byte-for-byte.
- **Per-register fidelity** (native builds): per-frame match rate per register class — freq (semitone-based), waveform, pulse, AD/SR, filter cutoff — per voice, over the real song length (post-`$FE` silence excluded).
- **Byte-exact**: 100% on every tracked register for every frame of the song. The project's crown-jewel standard (MoN Hawkeye sub2/3 achieve it).
- **Objective SF2II validation**: the instrumented editor's *actual* playback captured and diffed (`bin/sf2ii_vs_real.py`) — the truth-teller; headless metrics historically overstate (Galway "37 faithful" → 30/40 objective).

Measurement tools ladder: onset validators (`*_validate.py`) → per-frame fidelity (`mon_part_fidelity.py`, `romuzak_native_validate.py`) → real-SF2II capture (`sf2ii_vs_real.py`) → VICE audio A/B (`listen_compare.py`). See [PLAYBOOK.md §4](../players/PLAYBOOK.md).
